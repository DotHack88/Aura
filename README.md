# Aura 🎵

Aura is a modern Android application for seamless music streaming. Built entirely with Kotlin and Jetpack Compose, it features a fluid user interface, high-quality audio playback, and a smooth user experience.

## ✨ Features
- **Dynamic Search:** Find your favorite tracks and artists instantly.
- **Background Playback:** Full support for ExoPlayer and media notifications.
- **In-App Updates:** Aura automatically checks for updates via GitHub Releases and installs them directly within the app.
- **Beautiful UI:** Developed with Material 3 and custom animations.
- **History & Recommendations:** Keep track of what you listen to and get personalized recommendations.

## 🚀 Installation
1. Go to the [Releases](../../releases) page.
2. Download the latest `Aura.apk` file.
3. Open it on your Android device and authorize the installation.
*(For future updates, the app will automatically notify you and handle the download/installation process!)*

## 🛠 Tech Stack
- **Kotlin** & **Jetpack Compose**
- **Media3 (ExoPlayer)** for reliable audio playback
- **Coil** for asynchronous image loading
- **Room** for local database and history
