Quale struttura per la homepage di presentazione?

Tutti mantengono l'identità visiva Aura (bg scuro, glassmorphism, viola #a855f7). Scegli quella che preferisci.

Aura
La tua musica, ovunque

A — Centro eretto

Hero centrato verticalmente: logo grande, tagline, un solo CTA. Niente griglia, solo scroll verso il basso per feature/stack/download.

Aura

B — Griglia feature

Hero breve seguito subito da una griglia di feature card (6 slot). Ottima per mostrare a colpo d'occhio cosa fa l'app.

C — Sezioni in flow

Hero + sezioni consecutive (feature, stack, come funziona, tabella download). Più lunga da scrollare ma copre tutto il contenuto del README in un unico scorrimento.

Pro (consigliato)

  • A: massima impatto visivo, semplice, veloce da costruire
  • B: ottima per chi cerca subito le feature
  • C: copre tutto il contenuto del README senza salti

Contro

  • A: poco spazio per le feature, bisogna scrollare molto
  • B: la griglia può sembrare "da template"
  • C: meno d'impatto iniziale, più lunga

Clicca una card per selezionare, poi scrivi qui che ne pensi.
